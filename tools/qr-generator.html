Tips

  • Higher error correction lets the QR still scan if partially obscured — but makes the code denser.
  • For dark-on-light QR codes, keep contrast high (avoid similar hues).
  • URLs with long query strings work fine — but shorter URLs scan faster.
  • Uncheck "Auto-update" if you want to manually click Generate after typing.
